# Dorfik's GUI for QEMU

A modern WinUI 3 front-end for QEMU on Windows. Create machines from presets (Windows 11, Linux, Android-x86…), pick an ISO and press Start.
If QEMU is missing it is downloaded and installed automatically.

Installers: `.exe` (Inno Setup) and `.msi` (WiX) on the Releases page.
QEMU itself is GPL-2.0 and is downloaded from qemu.weilnetz.de.
